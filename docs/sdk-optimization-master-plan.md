# SDK 优化总规文档（统一版）

## 统一原则

- 固定 5 节点（`A/B/C/D/E` 各 1 个）
- 不使用未入选节点
- 数据面不大改，优先增强控制面

## 控制面能力

- Secret 解析（明文/加密）
- 多存储并发拉取
- 本地缓存与 `ETag/304`
- 固定选点与回退
- 状态机、熔断、退避
- 诊断与自检

## 发布策略

1. 先明文联调打通全链路
2. 再启用 RSA token
3. 最后启用 AAR 内置私钥与策略调参

## 验收口径

- 冷启动可用
- 节点失败自动回退
- 不发生重试风暴
- 固定节点边界不被突破
- Android 对接稳定输出本地端口
