# SDK 优化建议与实施文档

## 目标

- 兼容 `Android + iOS + Windows`
- 保持固定节点策略，降低攻击面
- 提升弱网、攻击场景的可用性
- 支持配置拉取、缓存、回退、可观测

## 当前能力

- 本地代理转发
- TLS + obfs
- 连接池复用

## 关键优化项

1. 配置控制面：`HEAD/ETag/304` + 本地缓存
2. 固定选点：每设备固定 `A/B/C/D/E` 各 1 个
3. 固定集合内回退：不使用未入选节点
4. 状态机：`NORMAL/DEGRADED/ATTACK/RECOVERING/EMERGENCY`
5. 熔断与指数退避：避免重试风暴
6. DNS fallback：固定集合全失败后进入 `app_domain` 回退

## 实施里程碑

- M1: 配置拉取 + 缓存 + 回退
- M2: 固定选点 + 候选切换
- M3: 状态机 + 熔断 + 退避
- M4: 跨端对齐 + 压测 + 故障演练
